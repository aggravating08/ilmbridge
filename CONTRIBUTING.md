# Contributing

Use Python 3.10+ and run `python3 -m unittest discover -s tests -v` before a pull request. The core app has no install step.

For bug reports include reproducible steps and fictional sample text. Never upload private course notes, student records, model credentials, or generated runtime files. Explain the problem your change solves, and add focused tests where behavior changes. Check the UI with a keyboard and at narrow widths.

For an initial contribution, improve language evaluation, add a retrieval edge case, or improve accessibility. Changes are contributed under the project's MIT license. Please be respectful, credit others' work, and describe AI assistance honestly.
